# 🐧 Palmer Penguins: End-to-End Data Science & Machine Learning Pipeline

An end-to-end data science project analyzing morphological variations, statistical hypothesis testing, and predicting species using machine learning on the **Palmer Archipelago Penguins Dataset** ($N = 333$).

---

## 📌 Project Overview
This repository contains a 5-week structured data science internship project that covers the complete data lifecycle:
1. **Exploratory Data Analysis (EDA):** Univariate & bivariate distribution profiling.
2. **Data Visualization:** Multi-variable relationship plots, boxplots, and correlation heatmaps.
3. **Inferential Statistics & Hypothesis Testing:** One-Way ANOVA, Two-Sample T-Tests, and Chi-Square Tests of Independence.
4. **Supervised Machine Learning:** Building, training, and evaluating a Random Forest Classifier (**98.5% Accuracy**).
5. **Strategic Recommendations:** Translating technical metrics into field-research and conservation insights.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 3.x
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Seaborn, Matplotlib
* **Machine Learning & Statistics:** Scikit-learn, SciPy
* **Documentation:** Microsoft Word / Google Docs

---

## 📊 Key Results & Findings
* **Species Predictability:** `bill_length_mm` and `flipper_length_mm` contribute to over **60%** of feature importance in classifying species.
* **Habitat Specificity:** *Gentoo* penguins exclusively reside on **Biscoe Island**, while *Chinstrap* penguins reside on **Dream Island**.
* **Statistical Significance:** ANOVA confirmed significant body mass variation across species ($F = 341.89, p < 0.001$).
* **Model Performance:** Random Forest achieved **98.5% Accuracy** with optimal multi-class confusion matrix metrics.
